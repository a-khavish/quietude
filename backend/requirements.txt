# Quietude - core backend dependencies (Linux)
#
# Everything Quietude needs to run at all: the server, local persistence and
# encryption, and face login. If any of this won't install, Quietude won't
# start, so install.sh treats a failure here as fatal.
#
# The voice stack is deliberately NOT here - see requirements-voice.txt.
#
# ---------------------------------------------------------------------
# On version floors instead of exact pins
# ---------------------------------------------------------------------
# This file used to pin exact versions. That turned out to be actively
# harmful: several of these ship interpreter-specific wheels, and support
# for a new Python arrives in a *new* release. Pinning an older one means
# that on a newer interpreter pip finds no wheel at all and the install
# dies - which is exactly what happened on Python 3.14, where an exact
# pin of piper-tts==1.2.0 dragged in a C++ dependency that has no 3.14
# wheels and never will.
#
# So: a floor chosen as a version whose API Quietude is known to work
# against, and an upper bound only where a major release could plausibly
# break something. New Python versions then resolve to new wheels on
# their own.
#
# Verified working as of this writing: Flask 3.1.3, Werkzeug 3.1.9,
# cryptography 50.0.2, numpy 2.4.6, opencv-contrib 5.0.0.93 - on Python
# 3.11 and 3.14.

Flask>=3.0,<4
Werkzeug>=3.0,<4

# Fernet for the Gemini API key; werkzeug's scrypt for the password.
cryptography>=42

numpy>=1.26

# Face detection + LBPH recognition. The contrib build is required:
# cv2.face lives in opencv_contrib and plain opencv-python doesn't have
# it. Headless because nothing in the backend opens a window - the camera
# is the browser's - so the GUI half is dead weight that also pulls in
# X11 libraries a Wayland-only system has no other reason to install.
#
# 4.9 is the floor; 5.x is tested and fine (cv2.face, LBPH train/save/
# read/predict and the bundled Haar cascade all verified on 5.0).
opencv-contrib-python-headless>=4.9,<6
