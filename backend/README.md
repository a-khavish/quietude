# Quietude

**Nothing leaves this room.**

A personal assistant for Linux that runs entirely on your own machine.
You give it a name. It listens, talks back, and nothing you say goes
anywhere.

Speech recognition, speech synthesis and face recognition all run
locally. The assistant has no name until you give it one — and the name
you choose becomes the wake word.

## Installing

This package is the backend. The assistant is installed as a whole, with
its interface, its models and its desktop entry, by the installer in the
repository:

```bash
git clone https://github.com/a-khavish/quietude.git
cd quietude
./install.sh
```

Full documentation, screenshots and a demo:
**https://github.com/a-khavish/quietude**
